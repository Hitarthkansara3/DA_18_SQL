# SQL Sales Data Analytics

## Overview

A MySQL project focused on sales data analysis using CRUD operations, aggregate functions, filtering, grouping, and sorting.

## Topics Covered

- SELECT, INSERT, UPDATE, DELETE
- WHERE, AND, OR, IN, BETWEEN, LIKE
- COUNT(), SUM(), AVG(), MIN(), MAX()
- GROUP BY, HAVING, ORDER BY
- Sales performance and business analysis

## Dataset

The `sales_transactions` table contains 30 sample sales records across product categories, cities, salespersons, payment modes, and customer types.

## Tasks

The project includes 20 SQL practical tasks covering sales summaries, category analysis, salesperson performance, customer segmentation, discount analysis, and CRUD operations.
