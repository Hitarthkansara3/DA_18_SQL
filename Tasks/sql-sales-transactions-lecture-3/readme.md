# SQL Sales Transactions - Lecture 3

This repository contains SQL practice tasks based on a sales transactions database.

## Topics Covered

- Creating databases and tables
- Inserting data
- SELECT queries
- WHERE conditions
- AND / OR operators
- IN operator
- NOT conditions
- BETWEEN operator
- Comparison operators
- Multiple conditions
- Parentheses with complex conditions
- ORDER BY

## Database Structure

The project uses a `sales` table with the following columns:

- `transaction_id`
- `customer_name`
- `product_name`
- `category`
- `quantity`
- `unit_price`
- `discount_percent`
- `city`
- `payment_mode`
- `salesperson`
- `customer_type`

## Tasks

The SQL file contains 20 practice tasks covering different filtering and conditional query scenarios.

## Technologies Used

- SQL
- MySQL

## Purpose

The purpose of this project is to practice SQL filtering, logical operators, sorting, and writing queries using sales transaction data.
