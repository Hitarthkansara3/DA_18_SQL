# SQL School & Employee Database - Lecture 2

This repository contains SQL practice tasks covering database and table creation, data insertion, and basic SQL queries.

## Topics Covered

- Creating a database
- Using a database
- Creating tables
- Defining columns and data types
- Primary keys
- Inserting records
- Selecting data using `SELECT *`

## Tables

### Students

The `Students` table contains:

- `Student_ID`
- `StudentName`
- `Age`
- `Course`
- `Marks`

### Employees

The `Employees` table contains:

- `Emp_ID`
- `Emp_Name`
- `Department`
- `Salary`
- `Date_Joined`

## Tasks

- Create `SchoolDB` database
- Create `Students` table
- Insert student records
- Retrieve student records
- Create `Employees` table
- Insert employee records
- Retrieve employee records
